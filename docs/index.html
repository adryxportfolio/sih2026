Installing on Android

  1. Download the APK on the phone.
  2. Allow Install unknown apps for your browser or file manager.
  3. Open the downloaded file and install. Android 7.0 or newer.
  4. Tap the demo entry to see the full journey — no account or network needed.

Accounts

Officers do not self-register. An administrator creates each account against a verified employee ID, which is what ties a competency record to a real post rather than to whoever typed an email address. The same credentials open the phone app and the desktop workspace.

Running the workspace

The workspace needs Docker Desktop and a local model server. See workspace-demo-setup.md for the full runbook, and CLAUDE.md in the repository root for the architecture and the failure modes worth knowing in advance.
